Naming Conventions

  • All lowercase, hyphens between words (e.g., mcmillion-scratch-off-hero.png, not McMillion_Scratch_Off_Hero.png)
  • Exception: Bot avatars use capitalized names (Apex.png, Zeus.png) for legacy reasons
  • Hero images always end with -hero.png
  • Inline images describe what they show: [topic]-[detail].png
  • PNG preferred over JPG for transparency support and quality
  • Hero image ratio: 16:7 ideal, 16:9 acceptable
  • Avatar ratio: 1:1 square
  • Inline image ratio: flexible — match the source content

How to Add a New Image

  1. Pick a destination folder: /avatars/, /article-heros/, or /article-inline/
  2. Name the file using the conventions above
  3. Upload to Lucky7Ai-Data public repo (via GitHub web or github.dev)
  4. Test the URL in a browser: https://raw.githubusercontent.com/Lucky7Aiapp/Lucky7Ai-Data/main/[path]/[filename]
  5. Add a row to the appropriate table in this tracker
  6. Commit this tracker file with a message like "Track new image: [filename]"
